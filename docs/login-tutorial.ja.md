# GitHub ログインチュートリアル（初心者向け）

このチュートリアルでは、日記を GitHub にバックアップする方法をゼロから説明します。所要時間は約10分で、**プログラミングの知識は一切不要**です。

---

## なぜ GitHub にログインするのか？

「墨辰DarkCube」は日記を**あなた自身の GitHub プライベートリポジトリ**に保存します：

- パソコンとスマホの日記が GitHub を通じて同期されます
- 端末を失くしたり壊したりしても、日記はクラウドに安全に残ります
- プライベートリポジトリは他人から見えず、あなただけがアクセスできます

---

## ステップ 1：GitHub アカウントの作成（お持ちの方はスキップ）

1. ブラウザで <https://github.com/signup> を開きます
2. メールアドレス・パスワード・ユーザー名を入力し、案内に従って登録します（メール認証が必要な場合があります）

> この作業は一度だけです。パソコンやスマホを変えても、同じアカウントを使います。

---

## ステップ 2：アクセストークンの作成

トークンは鍵のようなもので、アプリが代わりに GitHub へアクセスするために使います。**次の項目を正確に設定してください**：

1. <https://github.com/settings/personal-access-tokens/new> を開きます
2. **Token name** に好きな名前（例：`darkcube-diary`）を入力
3. **Expiration（有効期限）**：**90 days** を推奨（期限切れ後は再生成）
4. **Repository access**：**All repositories**（すべてのリポジトリ）を選択

   > ⚠️ ここが重要：**Only select repositories** を選ぶと、アプリが日記リポジトリを自動作成できなくなります。

5. **Permissions（権限）** までスクロールし、**Add permissions** から次を追加：
   - **Contents** → **Read and write**
   - **Administration** → **Read and write**
6. ページ下部の **Generate token** をクリック
7. `github_pat_...` で始まる長い文字列を**すぐにコピー**してください（**一度しか表示されません**）

---

## ステップ 3：アプリ内でログイン

1. 墨辰DarkCube を開き、上部の **「GitHub ログイン」** をタップ
2. ダイアログに先ほどコピーしたトークンを貼り付け
3. **リポジトリ名**は既定の `darkcube-diary` のままでOK（好きな名前でも可）
4. **「ログインして作成」** をタップ

アプリがトークンを検証し、GitHub 上に**プライベートリポジトリを自動で作成**します。手動での作成は不要です。

---

## ステップ 4：同期を開始

1. **設定** → **同期** を開く
2. **「↑ 送信」** または **「↓ 取得」** をタップし、数秒待つ
3. 「送信完了」「取得完了」と表示されれば成功です
4. **自動同期** をオンにすると、アプリ起動時やネットワーク復帰時に自動で同期されます

GitHub のウェブサイトでリポジトリを開くと、`diary/entries/` フォルダ内に日記（1日1つの Markdown ファイル）が見えます。

---

## よくある質問

**Q：「トークンが無効または期限切れ」と表示される？**
新しいトークンを生成（ステップ 2）して、もう一度ログインしてください。

**Q：「Contents の権限がない」と表示される？**
ステップ 2-5 に戻り、**Contents** が **Read and write**、Administration も設定されているか確認してください。

**Q：「リポジトリ名が既に存在」または作成に失敗？**
ログインダイアログの**リポジトリ名を新しい名前に変更**（例：`my-diary-2026`）して再試行してください。

**Q：「リポジトリが空」または同期失敗？**
一度再試行してください。それでも失敗する場合は、エラーのスクリーンショットを作者（設定 → 情報 → 作者のB站ホーム）に送ってください。

**Q：トークンを忘れた？**
トークンは一度しか表示されません。<https://github.com/settings/tokens> で再生成し、アプリで再ログインしてください。

---

## セキュリティ上の注意

- トークンはアカウントの鍵の一部です：**他人に渡したり、スクリーンショットをネットに公開しないでください**
- トークンはあなたの端末（ローカルブラウザ）にのみ保存されます
- 漏えいが疑われる場合は <https://github.com/settings/tokens> で削除し、再生成してください
