# 墨辰DarkCube · 宣传片脚本

> **风格基调**：Apple 式。安静、克制、留白。不罗列功能，只讲一个主张。
> **主片时长**：90 秒　**副片**：30 秒　**画幅**：16:9 主版 / 9:16 竖版

---

## 一、创意核心

**一句话主张**：有些话，只说给自己听。

**冲突**：主流云笔记把最私密的文字放进别人的服务器；而加密工具又要你记住随时可能遗忘的密钥。

**解法**：墨辰DarkCube —— 日记先存在你自己的设备，再同步进**你自己的 GitHub 私有仓库**；仓库里不是明文，而你**不需要记住任何密钥**。

**情绪曲线**：私密（静）→ 不安（快）→ 揭示（亮）→ 掌控（稳）→ 温暖（慢）→ 余韵（静）

---

## 二、视觉与声音规范

| 项目 | 规范 |
|---|---|
| 色彩 | 纯黑 `#000000` → 近黑 `#0A0A0A`（App 主色）→ 纸白 `#F5F5F5` 三态切换 |
| 字体 | 中文：苹方 / 思源黑体；英文：SF Pro Display。一律 Light 或 Regular，**不用粗体强调** |
| 动效曲线 | 全线统一 `cubic-bezier(0.22, 0.61, 0.36, 1)`（与 App 内完全一致），时长 0.4–0.6s |
| 转场 | 硬切为主 + 12 帧黑场呼吸。不使用缩放、旋转、故障等花哨转场 |
| 镜头 | 微距特写 + 缓慢推拉。所有移动速度不超过画面宽度的 5%/秒 |
| 音乐 | 极简合成器 pad + 单音钢琴，BPM 96。**前 12 秒几乎静默** |
| 音效 | UI 轻触 `-24dB`、翻页、打字声。全程低于音乐 6dB |
| 旁白 | **无旁白**。仅字幕，居中偏下，逐字浮现（每字 60ms） |
| 节奏 | 慢起（12s）→ 快剪（30s）→ 慢收（28s）→ 静默（8s） |

## 六、制作与交付提示

1. **录屏规格**：Android 真机 + Windows 客户端各录 60fps；关键动作用 120fps 录制后放慢 50%。
2. **素材占位**：**不要**出现真实日记内容。统一使用示例文案（如「今天下了很大的雨，我在窗边坐了很久。」）。
3. **仓库镜头**：GitHub 页面需打码账号名与 Token；`.enc` 文件名可保留（正好说明混淆）。
4. **图标镜头**：直接从 `build/icon.png` 取 512px 素材做微距推拉，钢笔线条与 App 内一致。
5. **安全提示**：如片中展示同步过程，避免暴露真实 Token；建议用演示账号或纯动画代替。
6. **落版二维码**：结尾可加 Releases 页二维码（GitHub: sinsine/DarkCube）。
7. **音乐版权**：建议使用可商用极简电子曲库（如 Artlist / Epidemic Sound 中 "minimal piano + pad" 类目），BPM 96 附近便于卡点。
8. **竖版适配**：第 4 幕字幕改上下结构（字幕在上、画面在下），其余分镜不变。
