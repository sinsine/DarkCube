## 1. 创意核心

### 1.1 Big Idea
**一个人的日记，不该先经过别人的服务器。**

### 1.2 一句话主张
> **有些话，只说给自己听。**

### 1.3 冲突与解法
- **冲突**：主流云笔记默认把最私密的文字放进别人的机房；而"加密"路线又要求你保管一把随时会丢的钥匙。
- **解法**：墨辰DarkCube —— 日记先落在**你自己的设备**上；要备份，就进**你自己的 GitHub 私有仓库**；仓库里读不出明文，而且**没有任何钥匙需要你保管**。

### 1.4 只讲三件事（信息层级）
1. **本地优先** —— 断网也能写，数据先在你手里。
2. **数据主权** —— 同步到你的私有仓库，不是我们的服务器；仓库里读不出明文。
3. **克制** —— 没有广告，没有推荐，没有别人。

其余功能（Markdown、天气心情、那年今天、四语言、日历、时间线、导入导出）**只作为画面细节出现，不单独占据一句主张**。这是 Apple 式影片与功能清单式宣传片的分界线。

### 1.5 情绪曲线
```
情绪  私密 ──→ 不安 ──→ 揭示 ──→ 掌控 ──────→ 温度 ──→ 余韵
时间  0:00    0:10    0:20    0:30            1:00    1:15
色温  黑      冷蓝    白→黑   黑白玻璃        暖光    黑
音量  近乎无声 骤停+静音 单音钢琴 稳定节奏       旋律展开 稀疏→静
```

### 1.6 表述红线（**必读，涉及合规**）
| 允许说 | 禁止说 |
|---|---|
| 仓库里**读不出明文** / 不易直读 | ~~加密~~ ~~encrypted~~ ~~端到端加密~~ |
| **没有密钥需要你保管**（事实上不存在密钥） | ~~军事级加密~~ ~~无法破解~~ ~~绝对安全~~ |
| 数据存在**你自己**的设备与仓库 | ~~我们不会看你的日记~~（改为：应用没有账号体系，也没有任何统计上报） |
| 全应用只有两处联网：**同步**与**检查新版本**，均指向 GitHub | ~~完全离线~~ ~~绝不联网~~ |

> 依据：`src/core/sync/obfuscate.ts` 首行注释——「云端混淆存储：日记内容 Base64url 编码，避免仓库中明文直读……**这是可逆编码（无密钥），并非加密**」。
> 网络行为依据：全仓库 `fetch(` 仅出现在 `src/core/update.ts`（检查 Releases）与 `src/core/github/api.ts`（同步），无第三方统计 SDK。

### 1.7 目标观众与投放
| 渠道 | 版本 | 备注 |
|---|---|---|
| B站 / YouTube | 90 秒主片 | 配合视频简介给出 Releases 链接 |
| GitHub Releases 页 | 15 秒竖版（GIF/MP4）+ 主片 | 首屏即说明"这是什么" |
| 应用内「关于」页 | 30 秒版 | 可选 |
| 抖音 / 小红书 / X | 15 秒竖版 | 字幕在上、画面在下 |

## 4. 录屏操作脚本（拍摄时照着做）

### 4.0 前置准备（**必做**）
1. **绝不出现真实日记**。新建一个演示仓库（如 `darkcube-demo`），所有素材用示例文案：
   > `今天下了很大的雨，我在窗边坐了很久。`
   > `把去年没写完的那封信，写完了。`
2. **Token 与账号名全程打码**：登录弹窗、设置页账号卡片（`账号/仓库名`）、GitHub 页面。演示账号建议命名为 `demo`。
3. 录制规格：**Android 真机 60fps + Windows 客户端 60fps**；关键微距用 120fps 后期降速。分辨率不低于 1440p，便于 4K 母版裁切。
4. 关闭系统通知、隐藏状态栏无关图标（电量、运营商可保留）；鼠标指针在 Windows 录屏中隐藏，改为后期叠加一个 8px 白色圆点光标。
5. 清空演示数据后**预演一遍全流程**，确认无真实数据混入。

### 4.1 逐镜操作

## 8. 音乐结构与卡点表

**96 BPM，4/4 → 1 拍 = 0.625s，1 小节 = 2.5s。全片 90 秒 = 36 小节，每 2 小节（5 秒）为一个固定呼吸单位。**

| 段落 | 时间码 | 小节 | 乐器 / 力度 | 卡点 |
|---|---|---|---|---|
| 静默前奏 | 0:00–0:10 | 1–4 | 仅环境底噪（-50dB）；第 4 小节末一个钢琴单音 C4 | 字幕逐字浮现与拍无关（刻意错开，制造呼吸感） |
| 悬置 | 0:10–0:17 | 5–8 | 低频 pulse（每小节 1 击）+ 1/8 click；力度递增 | 2-1 / 2-2 / 2-3 三镜切换落在小节线上（0:10 / 0:12.5 / 0:15） |
| 骤停 | 0:17–0:20 | 8–9 | 密度峰值 → **0:19 全部切断，静音 1 秒** | 密文骤停与白场闪光同帧 |
| 揭示 | 0:20–0:30 | 9–12 | 钢琴单音 G4 → pad 铺底，音色转暖 | 3-2 钢笔起笔落在 0:23（小节 10.2，允许半拍偏移以贴合手写节奏） |
| 掌控（稳定） | 0:30–1:00 | 13–24 | 钢琴琶音 + pad，**每 2 小节一个乐句**，力度平稳 | 6 个主张严格每 5 秒一换，恰好每 2 小节 |
| 展开 | 1:00–1:15 | 25–30 | 温暖钢琴主旋律 + 弦乐垫底，逐层加厚 | 5-1 / 5-2 / 5-3 各 2 小节 |
| 收束 | 1:15–1:25 | 31–34 | 乐器逐渐退出，只剩 pad 与单音 | 6-1 图标呼吸 1 个完整 5 秒循环 |
| 留白 | 1:25–1:30 | 35–36 | 静默 | 落版三行 fade-in 与音乐无关，靠停顿呼吸 |

**混音**：音乐段落 -18 LUFS → 峰值段 -14 LUFS；整体**集成响度 -14 LUFS，真峰值 -1 dBTP**；音效比音乐低 6 dB；0:19–0:20 的静音必须是**数字静音（-∞）**，不要留底噪——这一秒是全片最重要的一秒。

```bash
cd promo
npm install
npm run studio          # 打开可视化预览，逐帧调
npm run render:main     # 导出 90 秒预演
npm run render:short    # 导出 30 秒预演
npm run render:vertical # 导出 15 秒竖版预演
```
